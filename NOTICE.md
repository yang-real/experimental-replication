# Attribution and Use

This repository contains an independent reproduction audit and supplementary
analysis scripts. It does not claim authorship of the original benchmark,
model architectures, datasets or published checkpoints.

Original resources:

- Paper: https://arxiv.org/abs/2604.18721
- Official code: https://github.com/Dineth14/Mamba-Segmentation
- Official checkpoints: https://huggingface.co/dineth18/Mamba-Segmentation
- LoveDA: https://github.com/Junjue-Wang/LoveDA

The official Mamba-Segmentation repository does not declare a repository
license through GitHub's license metadata. Consequently, this repository does
not redistribute the full upstream source tree. It references the official
commit and contains a patch with the local compatibility changes needed for the
experiments.

LoveDA has academic-use and non-commercial restrictions. Raw LoveDA data are not
included in this repository.
